## Question
Which license covers the repository?

## Evidence and constraints
The design report's tree (§6) and README draft (Appendix A) proposed MIT for code and CC BY 4.0 for the method, skills, and recipes.

## Resolution
Answered by the human in the charting session on 2026-11-18: "License: MIT for everything."

## Rationale
One permissive license for code, skills, method, and recipes keeps forking simple.

## Resulting map updates
T007 adds an MIT `LICENSE` for the whole repository; T014's README says MIT, replacing the appendix's split.
